# Contributing to Ribose projects

Thank you for contributing to a Ribose project.

## Ribose Contributor License Agreement

Before your first pull request can be merged in any Ribose GitHub
organization, you need to be covered by the Ribose Contributor License
Agreement (CLA). Sign once; one signature covers every Ribose
organization.

- **Individual contributors** — sign the Individual CLA at
  <https://cla.ribose.com/icla>. The `cla/ribose` check on your pull
  request reports the state. You can also sign from the pull request by
  commenting `@ribose-cla agree` and completing the one-click link the
  App replies with.
- **Corporate contributors** — if your employer has an executed
  Organization CLA, the employer's Point of Contact adds your GitHub
  handle to its Schedule A at <https://cla.ribose.com/organizations>, or
  you can request coverage there yourself. No individual signature is
  then needed.
- **The full guide** — the signing flows (including the automatic Ribose
  ID account created from GitHub) and the agreement text are at
  <https://github.com/riboseinc/cla/blob/main/docs/SIGNING.md>.

Where branch protection requires `cla/ribose`, an unsigned pull request
cannot merge. The check re-evaluates on the next push; a maintainer can
re-run it if it lags.

## Development conventions

The estate's development guidelines live in
<https://github.com/riboseinc/oss-guides>. A repository that carries its
own contributor guide or README takes precedence for that repository.
